# Escalonamento de processos

Material de estudo de Sistemas Operacionais sobre escalonamento de processos. A página reúne explicações, diagramas de Gantt, exemplos resolvidos e exercícios com respostas.

## Conteúdo

- Conceitos de chegada, burst, término, turnaround e tempo de espera
- FIFO (FCFS)
- SJF sem preempção
- SJF com preempção (SRTF)
- Round Robin
- Exercícios para praticar

## Usar localmente

Abra [`index.html`](index.html) em qualquer navegador. Não é necessário instalar dependências nem iniciar um servidor.

## Publicar com GitHub Pages

1. Crie no GitHub um repositório **público**, por exemplo `escalonamento-processos`.
2. Envie `index.html` e `README.md` para a branch `main` do repositório. Você pode fazer isso pela opção **Publish to GitHub** do VS Code ou usando Git no terminal.
3. No repositório, acesse **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e a pasta `/(root)`, depois salve.
5. Quando a publicação terminar, o GitHub mostrará o endereço da página na seção **Pages**. Compartilhe esse endereço para que outras pessoas possam estudar.

## Observação

As convenções de desempate e de entrada na fila podem variar conforme o enunciado. Confira sempre as regras usadas na sua disciplina.
